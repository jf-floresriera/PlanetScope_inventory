# 🧰 herramientas/

| Script | Uso |
|---|---|
| [`generar_gif_inventario.py`](generar_gif_inventario.py) | Regenera [`assets/inventario_animado.gif`](../assets/inventario_animado.gif) desde el inventario (CSV o Excel). Solo usa conteos, no imágenes. |

```bash
python herramientas/generar_gif_inventario.py "/content/drive/MyDrive/Purdue_TarSpot_Project/08_Planet_PlanetScope/INVENTARIO_PLANET_COMPLETO.csv"
```

Las animaciones SVG de [`assets/`](../assets) (`flujo_animado.svg`, `cuota_animada.svg`, `fenologia_animada.svg`)
son archivos de texto editables: los colores y textos se cambian directamente en el SVG.
